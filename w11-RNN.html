RNN 자연어처리 강의 핵심 정리 노트

개념 Sequence Model이란?

순서가 있는 데이터(시계열, 텍스트, 오디오, 영상)를 처리하는 모델. 이전 시점 정보가 있어야 다음을 예측 가능.

핵심 RNN vs 일반 신경망

일반 신경망: 각 입력 독립 처리 → o_t = f(x_t)

RNN: 과거 hidden state 반영 → o_t = f(x_t, h_{t-1})

h_t = tanh(h_{t-1}·W_hh + x_t·W_xh)
o_t = h_t · W_ho
시험 포인트 가중치 공유 (Weight Sharing)

모든 time step에서 W_hh, W_xh, W_ho를 공유. 같은 Cell을 반복 재사용하기 때문.

시험 포인트 tanh를 쓰는 이유

ReLU는 출력이 발산 → Normalization 필요. tanh는 출력을 [-1, 1]로 제한 → Gradient Vanishing 완화.

→ 이처럼 초기 random weight는 틀린 예측을 함. Backprop으로 학습.

시험 포인트 BPTT

BPTT (Backpropagation Through Time): 모든 시점의 loss 합 L에 대해 역전파. 시퀀스가 길면 gradient 소실.

Truncated BPTT: 일정 길이로 잘라 역전파 → 메모리·연산 절약, gradient 소실 방지. 단, hidden state는 계속 전달해 맥락 유지.

구조 Multi-layer RNN (Stacked RNN)

RNN을 세로로 여러 층 쌓은 구조. 상위 층으로 갈수록 더 추상적인 특징 추출.

RNN layer 1 (입력)
시험 포인트 Bidirectional RNN

Forward(→) + Backward(←) 두 방향으로 처리. 각 시점의 hidden state를 concatenate.

h→_t = f1(h→_{t-1}, x_t) ← 과거 맥락
h←_t = f2(h←_{t+1}, x_t) ← 미래 맥락
h_t = [h→_t ; h←_t] ∈ R^{2h} ← 차원 2배
활용 1
Sequence tagging (품사 태깅)
활용 2
Text classification
활용 3
Sentence encoding
핵심 아이디어 LSTM이 필요한 이유

Vanilla RNN은 Short-term memory 문제: 시퀀스가 길면 오래된 정보의 gradient 소실.

LSTM은 Cell State(c_t)라는 별도 통로로 장기 정보 보존 + 덧셈 연산으로 gradient 소실 완화.

시험 포인트 4가지 게이트 — 한 줄 요약
Forget Gate (f_t)
"무엇을 잊을 것인가?"
f_t = σ(W_f·[h_{t-1}, x_t] + b_f)
0→망각, 1→기억
Input Gate (i_t)
"무엇을 기억할 것인가?"
i_t = σ(W_i·[h_{t-1}, x_t] + b_i)
Cell Candidate (g_t / C̃_t)
"무엇을 새롭게 저장할 것인가?"
g_t = tanh(W_C·[h_{t-1}, x_t] + b_C)
Output Gate (o_t)
"무엇을 내보낼 것인가?"
o_t = σ(W_o·[h_{t-1}, x_t] + b_o)
시험 포인트 Cell State & Hidden State 업데이트
C_t = f_t ⊙ C_{t-1} + i_t ⊙ g_t
h_t = o_t ⊙ tanh(C_t)

덧셈(+) 연산 → gradient가 끊기지 않고 흐름 (Uninterrupted gradient flow)

핵심 GRU = LSTM의 경량화 버전

LSTM의 3게이트 + Cell State 구조를 단순화. 파라미터 감소, 빠른 수렴, 과적합 완화.

LSTM
게이트: Forget / Input / Output (3개)
상태: Cell State(c_t) + Hidden(h_t)
파라미터 많음, 표현력 ↑
GRU
게이트: Update / Reset (2개)
상태: Hidden(h_t)만 사용
파라미터 적음, 속도 ↑
시험 포인트 GRU 수식
r_t = σ(W_r·h_{t-1} + U_r·x_t + b_r) ← Reset gate
z_t = σ(W_z·h_{t-1} + U_z·x_t + b_z) ← Update gate
h̃_t = tanh(W·(r_t ⊙ h_{t-1}) + U·x_t + b) ← 후보 hidden
h_t = (1 − z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t ← 최종 hidden

Reset gate (r_t): 과거 정보를 얼마나 무시할지. 0이면 과거 완전 무시.

Update gate (z_t): LSTM의 Forget+Input을 합친 역할. 과거 vs 새 정보 비율 결정.
