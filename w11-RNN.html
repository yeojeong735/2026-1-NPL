순서가 있는 데이터(시계열, 텍스트, 오디오, 영상)를 처리하는 모델. 이전 시점 정보가 있어야 다음을 예측 가능.

시험 포인트 4가지 구조 — 반드시 암기

핵심 RNN vs 일반 신경망

일반 신경망: 각 입력 독립 처리

o_t = f(x_t)

RNN: 과거 hidden state 반영

o_t = f(x_t, h_{t-1})
h_t = tanh(h_{t-1}·W_hh + x_t·W_xh) ← hidden state 업데이트
o_t = h_t · W_ho ← output 계산
시험 포인트 가중치 공유 (Weight Sharing)

모든 time step에서 W_hh, W_xh, W_ho를 공유. 같은 recurrent cell을 반복 재사용하기 때문. 파라미터 수가 입력 길이와 무관하게 일정.

시험 포인트 tanh를 쓰는 이유

ReLU는 출력값이 발산 → Normalization 필요. tanh는 출력을 [-1, 1]로 제한 → Gradient Vanishing 문제 완화.

시험 포인트 BPTT vs Truncated BPTT
BPTT
모든 시점의 loss 합 L에 대해 역전파. 시퀀스가 길수록 gradient 소실 심화.
Truncated BPTT
일정 길이로 잘라 역전파. hidden state는 계속 전달 → 맥락 유지. 메모리·연산 절약.
구조 Multi-layer RNN (Stacked RNN)

RNN을 세로(계층 축)로 여러 층 쌓은 구조. 상위 층일수록 더 추상적인 특징 추출. 가로(시간 축)는 시퀀스 길이.

RNN layer 3 ← 가장 추상적인 표현
↑ hidden state 전달
RNN layer 2
↑ hidden state 전달
RNN layer 1 ← 입력 시퀀스
시험 포인트 Bidirectional RNN

Forward(→)와 Backward(←) 두 방향으로 처리. 각 시점의 hidden state를 concatenate → 과거·미래 맥락 동시 반영.

h→_t = f1(h→_{t-1}, x_t) t = 1,2,...,n ← 과거 맥락
h←_t = f2(h←_{t+1}, x_t) t = n,n-1,...,1 ← 미래 맥락
h_t = [h→_t ; h←_t] ∈ R^{2h} ← 차원이 2배

활용:

활용 1
Sequence tagging (품사 태깅)
활용 2
Text classification
활용 3
Sentence encoding
핵심 아이디어 LSTM이 필요한 이유

Vanilla RNN은 Short-term memory 문제: 시퀀스가 길면 오래된 정보의 gradient가 소실되어 학습 불균형 발생.

LSTM은 Cell State(c_t)라는 별도의 장기 기억 통로를 추가. 덧셈(+) 연산으로 gradient를 멀리까지 전달.

시험 포인트 4가지 게이트 — 각각의 역할
Forget Gate (f_t)
"무엇을 잊을 것인가?"
f_t = σ(W_f·[h_{t-1}, x_t] + b_f)
0 → 완전 망각, 1 → 완전 기억
Input Gate (i_t)
"무엇을 기억할 것인가?"
i_t = σ(W_i·[h_{t-1}, x_t] + b_i)
새 정보 중 저장할 비율 결정
Cell Candidate (g_t)
"무엇을 새롭게 저장할 것인가?"
g_t = tanh(W_C·[h_{t-1}, x_t] + b_C)
과거+현재 조합 → 후보 정보
Output Gate (o_t)
"무엇을 내보낼 것인가?"
o_t = σ(W_o·[h_{t-1}, x_t] + b_o)
Cell State 중 출력할 부분 선택
시험 포인트 Cell State & Hidden State 업데이트 수식
C_t = f_t ⊙ C_{t-1} + i_t ⊙ g_t ← 덧셈 연산 → gradient 소실 완화
h_t = o_t ⊙ tanh(C_t) ← 최종 hidden state (출력)

덧셈(+) 연산으로 Cell State를 통해 gradient가 전 시퀀스에 걸쳐 안정적으로 흐름 → Uninterrupted gradient flow

핵심 GRU = LSTM의 경량화 버전

LSTM의 복잡성·연산 효율 문제를 해결하기 위해 구조 단순화.

LSTM
게이트 3개: Forget / Input / Output
상태 2개: Cell State(c_t) + Hidden(h_t)
파라미터 많음, 표현력 높음
GRU
게이트 2개: Update / Reset
상태 1개: Hidden(h_t)만 사용
파라미터 적음, 속도 빠름
시험 포인트 GRU 수식
r_t = σ(W_r·h_{t-1} + U_r·x_t + b_r) ← Reset gate
z_t = σ(W_z·h_{t-1} + U_z·x_t + b_z) ← Update gate
h̃_t = tanh(W·(r_t ⊙ h_{t-1}) + U·x_t + b) ← 후보 hidden state
h_t = (1 − z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t ← 최종 hidden state
Reset gate (r_t)
과거 정보를 얼마나 무시할지 결정. r=0이면 과거 완전 무시, r=1이면 그대로 반영.
Update gate (z_t)
LSTM의 Forget gate + Input gate를 합친 역할. 과거 vs 새 정보의 비율을 결정.
